Uygulama kütüphanesi önerisi

Motionmotion/reactÖnerilen

Basit geçişler (hover, popover, toast, kutucuk) yalnızca CSS ile, aşağıdaki değişkenlerle yazılır. Motion yalnızca CSS’in zorlandığı üç yerde devreye girer: çıkış animasyonu (AnimatePresence: toast, silinen kart, kapanan modal), yerleşim ve paylaşılan öğe (layout, layoutId: kart → modal, satırın Tamamlananlar’a inişi, ızgarada komşuların kayması) ve azaltılmış hareketin tek noktadan yönetimi (MotionConfig reducedMotion="user").

React Router v7 + Vite ile doğrudan çalışır; MIT lisanslı, ağaç sallanabilir, uygun animasyonları Web Animations API ile ana iş parçacığı dışında oynatır. GSAP daha ağır, emirsel (ref + hook) ve kapalı lisanslı; ayrı Motion One paketi artık motion içinde.

Hareket ilkeleri

  1. 1

    Hareket anlam taşır. Nereden gelip nereye gittiğini gösterir: biten görev Tamamlananlar’a iner, kart yerinden modala büyür. Süs için hareket yok.

  2. 2

    Kısa olan iyidir. Uygulama içinde 320 ms üst sınır. Ne kadar sık görülürse o kadar kısa; klavyeyle tetiklenen eylem neredeyse anlık.

  3. 3

    Giriş ease-out, çıkış ease-in. Çıkış girişin yaklaşık %75’i. Linear yalnızca ilerleme çizgisi ve ışıltıda.

  4. 4

    Yalnızca transform ve opacity. Layout tetiklemeyen iki özellik 60 fps’i korur. Yükseklik gereken tek yer alt görev listesi.

  5. 5

    Her hareket kesilebilir. Animasyon girdiyi kilitlemez; yarıda kesilirse bulunduğu yerden geri döner, baştan başlamaz.

  6. 6

    Zemin sakin kalır. Ortam hareketi yalnızca giriş ekranında, düşük kontrastlı ve 8 sn’den yavaş. Uygulama içinde ortam hareketi yok.

Azaltılmış hareket kuralı

  • Kapanır: kayma, ölçek, paralaks, ortam döngüleri, ışıltı.
  • Kalır: anlam taşıyan durum değişimi, 120 ms saydamlıkla; ilerleme çizgisi durağan.
  • Kaynak: sistemdeki prefers-reduced-motion ve Ayarlar’daki “Hareketi azalt” (Sistem / Açık / Kapalı).
  • JS: matchMedia değişimi dinlenir; süren animasyon anında durur.
/* :root içinde — süreler */--dur-micro: 120ms;--dur-small: 180ms;--dur-medium: 240ms;--dur-large: 320ms;--dur-ambient: 11s; /* 8–14 s */
/* :root içinde — eğriler */--ease-out: cubic-bezier(.25, 1, .5, 1);--ease-in: cubic-bezier(.5, 0, .75, 0);--ease-spring: cubic-bezier(.2, .8, .2, 1);--ease-inout: cubic-bezier(.65, 0, .35, 1);--ease-ambient: cubic-bezier(.45, 0, .55, 1);
